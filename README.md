## 💻 Featured Project

### 🧠 [BrainLoop — Learn it. Keep it.](https://uttamest.github.io/brainloop/)

**An interactive flashcard application designed around active recall and spaced repetition.**

BrainLoop is a browser-based learning application that helps users organize study materials, create personalized flashcard decks, practice concepts, and monitor learning progress through a responsive and intuitive interface.

**Key Features**

- Create, edit, organize, and manage personalized flashcard decks.
- Practice active recall using interactive question-and-answer cards.
- Rate recall performance to guide subsequent review sessions.
- Schedule revisions through a tiered, interval-based review system.
- Monitor learning activity and progress.
- Import and export decks using JSON files.
- Store study data locally in the browser.
- Access the application across desktop and mobile devices.

**Technology Stack:** HTML · CSS · JavaScript · Browser Storage
